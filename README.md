# Hi, I'm Yared 👋

Computer science student at **Haramaya University**, Ethiopia. I build the backend side of web apps: APIs, databases, payments, and admin tools, mostly with **Node.js, TypeScript, MongoDB and React**.

## Featured project: Haramaya Delivery

A delivery platform for university students. They order from the Harar and Dire Dawa markets, pay with Telebirr or CBE, and pick up at one address on campus.

- Automatic payment receipt verification for **Telebirr** and **CBE**, with a manual review fallback
- Admin dashboard for products, payment review and orders, with **QR-code pickup**
- Live: **[hu-delivery.vercel.app](https://hu-delivery.vercel.app)**
- Code: [backend](https://github.com/yaredkumera/haramaya-delivery-backend) · [frontend](https://github.com/yaredkumera/haramaya-delivery-frontend)
